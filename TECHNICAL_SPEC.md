# Technical Specification: Latent Reasoning Laboratory

## 1. Engine Boundaries
The engine consists of transparent, pure-NumPy models. No PyTorch or TensorFlow. This ensures mathematical exactness, lightweight deployment, and easy matrix extraction for Streamlit visualizers.

## 2. Synthetic Task Generator
- **Domain:** Modular Arithmetic.
- **Input Encoding:** $x = [\frac{a}{23}, \frac{b}{23}, \frac{c}{23}, \frac{d}{23}, \frac{n}{23}, \frac{\text{level}}{4}] \in \mathbb{R}^6$
- **Ground Truth:** Strictly computed via Python deterministic integer arithmetic. *Never* generated by a neural model.

## 3. Micro-Experiment 1 & 2: Tokenization & Embedding
- **Vocabulary ($V$):** Small fixed dictionary (e.g., 20 words).
- **Embedding Matrix ($E$):** Randomly initialized $E \in \mathbb{R}^{V \times d}$. 
- **Dynamic Resizing:** The engine must allow $d$ to be dynamically passed as a parameter to regenerate $E$ on the fly for the interactive dimension slider.

## 4. Micro-Experiment 3: Positional Encoding
- **Matrix ($P$):** A learned or sinusoidal matrix $P \in \mathbb{R}^{L \times d}$ where $L$ is sequence length.
- **Operation:** $H_0 = X + P$.
- **Extraction:** The engine must expose $X$, $P$, and $H_0$ independently so the UI can visually show the matrix addition.

## 5. Micro-Experiment 4: Self-Attention (Q, K, V)
- **Projections:** $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$
- **Matrices:** $Q = H_0 W_Q$, $K = H_0 W_K$
- **Scores:** $S = \frac{QK^T}{\sqrt{d_k}}$
- **Extraction:** The UI will request the specific row of $Q$ (e.g., $Q_i$ for the word "cat") and compute its dot product against all rows of $K$ in real-time, displaying $S_{i, j}$.

## 6. Micro-Experiment 5 & 6: Explicit vs. Latent Solver
- **Explicit Solver (Mode A):** Symbolic Python rules converting operations into string tokens (e.g., `["3 * 5 = 15", "7 + 15 = 22", "22 mod 11 = 0"]`).
- **Latent Solver (Mode B):**
  - **Encoder:** $S_0 = \text{ReLU}(W_{\text{enc}} x + b_{\text{enc}})$
  - **Recurrent Loop ($R$ rounds):** $S_{t+1} = S_t + \alpha \cdot W_2 \tanh(W_1 S_t + b_1)$
  - **Decoder:** $\hat{y} = \text{Softmax}(W_{\text{out}} S_R + b_{\text{out}})$
  - **Extraction:** Must return the full trajectory list $[S_0, S_1, ..., S_R]$ for heatmap and PCA visualizers.

## 7. Metrics & "Break It" Constraints
- Models must honestly evaluate outputs against ground truth.
- Pre-trained weights will be generated targeting Level 1 and 2 only.
- The UI will explicitly allow generating Level 3 and 4 tasks to intentionally trigger failure modes, demonstrating that latent reasoning is not infallible.

## 8. Evidence Labeling Schema
All text rendered in the UI referencing external papers must utilize the strict labeling schema:
- 🟢 **OUR RESULTS**
- 🔵 **PUBLISHED**
- 🟡 **ILLUSTRATIVE**
- ⚪ **PRIMARY SOURCE**
