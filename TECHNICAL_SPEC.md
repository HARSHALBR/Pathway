# Technical Specification: Latent Reasoning Laboratory

## 1. Engine Boundaries
The computational engine consists strictly of transparent, pure-NumPy models. No PyTorch, TensorFlow, or JAX. This ensures lightweight execution, zero GPU requirement, exact matrix extraction, and full determinism.

---

## 2. Synthetic Task Generator (`models/tasks.py`)
- **Domain:** Modular Arithmetic.
- **Input Encoding:** $x = [\frac{a}{23}, \frac{b}{23}, \frac{c}{23}, \frac{d}{23}, \frac{n}{23}, \frac{\text{level}}{4}] \in \mathbb{R}^6$
- **Difficulty Levels:**
  - Level 1: $a + b \pmod n$ (2 operands)
  - Level 2: $a + b \times c \pmod n$ (3 operands)
  - Level 3: $a \times b + c \times d \pmod n$ (4 operands)
  - Level 4: $(a + b) \times c + d \pmod n$ (4 operands)
- **Moduli:** Primes from $\{7, 11, 13, 17, 19, 23\}$.
- **Ground Truth:** Strictly computed via Python's deterministic integer arithmetic (`%` operator). Never generated by a neural model.

## 3. Educational Transformer (`models/transformer_demo.py`)
- **Dimensions:** $d_{\text{model}} = 4, d_k = d_v = 4, d_{\text{ff}} = 8$, single-head, single-layer.
- **Vocabulary:** 24 tokens including padding, pronouns, nouns, verbs, and punctuation.
- **Embedding Lookup:** $X = E[\text{token\_ids}] \in \mathbb{R}^{L \times 4}$.
- **Positional Encoding:** $P \in \mathbb{R}^{L \times 4}$, $H_0 = X + P$.
- **Attention Projections:**
  - $Q = H_0 W_Q \in \mathbb{R}^{L \times 4}$
  - $K = H_0 W_K \in \mathbb{R}^{L \times 4}$
  - $V = H_0 W_V \in \mathbb{R}^{L \times 4}$
- **Scaled Attention Scores:**
  $$S = \frac{Q K^T}{\sqrt{d_k}} \in \mathbb{R}^{L \times L}$$
- **Softmax Weights:**
  $$A_{ij} = \frac{\exp(S_{ij} - \max_k S_{ik})}{\sum_k \exp(S_{ik} - \max_m S_{im})}$$
- **Value Aggregation & Projection:** $\text{Out} = (A \cdot V) W_O \in \mathbb{R}^{L \times 4}$.
- **Residual & Layer Normalization:**
  $$\text{Res}_1 = H_0 + \text{Out}, \quad \text{LN}(z) = \frac{z - \mu}{\sqrt{\sigma^2 + \epsilon}}$$
- **Feed-Forward Network:** $\text{FFN}(z) = \max(0, z W_{\text{ff1}}) W_{\text{ff2}}$.

## 4. Mode A: Explicit Solver (`models/explicit_reasoning.py`)
- Rule-based symbolic solver converting arithmetic steps into string tokens based on operator precedence.
- Emits explicit token sequence: e.g., `["3 × 5 = 15", "7 + 15 = 22", "22 mod 11 = 0", "Answer: 0"]`.
- Tracks token count and zero internal state updates.

---

## 5. Mode B: Latent Reasoning Model (`models/latent_reasoning.py`)
- **Architecture:** Fixed configuration: $\text{state\_dim} = 48, \text{hidden\_dim} = 96, \text{max\_classes} = 23$.
- **Initial Encoding:**
  $$s_0 = \max(0, W_{\text{enc}} x + b_{\text{enc}}) \in \mathbb{R}^{48}$$
- **Recurrent Update Loop ($R$ rounds):**
  $$s_{t+1} = s_t + \alpha \cdot W_2 \tanh(W_1 s_t + b_1) \in \mathbb{R}^{48}$$
  with shared weights $W_1 \in \mathbb{R}^{96 \times 48}, W_2 \in \mathbb{R}^{48 \times 96}$, scalar $\alpha \in \mathbb{R}$.
- **Readout & Dynamic Modulus Softmax:**
  $$\text{logits} = W_{\text{out}} s_R + b_{\text{out}} \in \mathbb{R}^{23}$$
  $$\hat{y} = \arg\max_{k \in \{0 \dots n-1\}} \text{softmax}(\text{logits}[:n])_k$$
- **Training:** Pure NumPy Backpropagation Through Time (BPTT) with gradient clipping at norm 5.0.

## 6. Hebbian Synaptic Working Memory Simulation (`components/bdh_bridge.py`)
- Implements the discrete BDH working memory update from Kosowski et al. (2025):
  $$S_t = \lambda \cdot S_{t-1} + K_t^T \cdot V_t \in \mathbb{R}^{4 \times 4}$$
  $$O_t = Q_t \cdot S_t \in \mathbb{R}^4$$
- Interactive control: Retention coefficient $\lambda \in [0, 1]$.
